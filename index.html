How to run a plot
  1. Fix the substrate to the bed (a corner jig helps the brush pass line up).
  2. Optional: run Boundary check to confirm placement.
  3. Jog the pen tip to just touch the artwork’s bottom-left corner (pink dot). Every file zeroes there with G92.
  4. Run the pen G-code.
  5. Spread paint, swap in the brush, re-zero Z on the same corner (don’t move X/Y), and run the brush G-code.
